## Requirements
**Python 3** et **Git**

## Installation
Pour installer le projet voici les étapes à suivre : 

```bash
git clone https://github.com/mlouiseprrt734/projetVote.git
cd projetVote

python -m venv venv
source venv/Scripts/activate

(commande à exécuter pour le "source venv/Scripts/activate" sous powershell)
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\venv\Scripts\Activate.ps1

pip install -r requirements.txt
```
Vous pouvez lancer l'application avec la commande : 
```bash
python run.py
